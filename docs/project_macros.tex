\subsection{Acronyms}
    This section covers the acronyms used in the documents in this project.
    \begin{enumerate}[leftmargin=3\parindent]
        \item \textbf{API}: Application Programming Interface, the calls the front end makes to the back end.
        \item \textbf{CORS}: Cross-Origin Resource Sharing, this ensures that all resources served by the front-end only come from trusted domains to avoid security concerns.
        \item \textbf{CSRF}: Cross Site Request Forgery, this is a method of ensuring that other sites cannot impersonate the front end.
        \item \textbf{FERPA}: Family Educational Rights and Privacy Act, the law that protects the privacy of student education records.
        \item \textbf{HTTPS}: Hypertext Transfer Protocol Secure, the encrypted version of HTTP used for all calls to the back end.
        \item \textbf{JSON}: JavaScript Object Notation, the data format used by the API.
        \item \textbf{JWT}: JSON Web Token, used as an authentication token.
        \item \textbf{MVP}: Minimum Viable Product, the basic site running with users able to access it.
        \item \textbf{OAS}: OpenAPI Specification, the format used to document the API.
        \item \textbf{RSVP}: A reply that tells the host a user plans to attend an event.
        \item \textbf{SSO}: Single Sign On, logging in with the university account instead of a separate password.
        \item \textbf{UI}: User Interface.
        \item \textbf{UUID}: Universally Unique Identifier.
    \end{enumerate}

\subsection{Documents}
    This section covers the abbreviations for the documents in this project.
    \textbf{Bold} is the abbreviation \textit{Italics} is the document name, \underline{Underlined} is the filename.
    \begin{enumerate}[leftmargin=3\parindent]
        \item \textbf{PDS} \textit{Project Design Spec}: \underline{project\_design\_spec.pdf}
        \item \textbf{SDD}: \textit{Software Design Document}: \underline{Software\_Design\_Document.pdf}
        \item \textbf{SO}: \textit{Snapshot Objectives}: \underline{Snapshot\_Objectives.pdf}
        \item \textbf{SRS}: \textit{Software Requirement Specification}: \underline{Software\_Requirement\_Specification.pdf}
        \item \textbf{TRD}: \textit{TestRail Document}: \underline{TestRail\_Document.pdf}
        \item \textbf{UM}: \textit{User Manual}: \underline{User\_Manual.pdf}
        \item \textbf{WD}: \textit{Workflow Diagram}: \underline{Workflow\_Diagram.pdf}
    \end{enumerate}
